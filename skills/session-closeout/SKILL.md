# 会话收尾 (Session Closeout)

在会话即将结束、或任务完成后交付前，按下面顺序执行。

## 1. 整理会话标题（set_thread_title）
- 格式：`主题 - 核心动作`（先主题，后动作）
- 简短（≤ 20 字），一句话说清会话在做什么
- 不用「1」这类无意义标题；不用超长原文当标题；不加日期（列表自带时间）
- 一个对话中途换了主线、做了多件事时，并列关键动作
- 例：`Ollama 界面中文化 - 调研与工期评估`

## 2. 清理临时产物
- 删除本次自己生成的临时文件、中间脚本、调试输出
- 只保留用户需要的交付物在 outputs 目录
- 不删除用户原有文件

## 3. 交付前自检
- 每一处改动都能追溯到用户需求（无顺手改动、无多余抽象）
- 无未验证的假设
- 引用 outputs 交付物时使用绝对路径链接
